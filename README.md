## 📌 Project Overview

**Voice Infection Classifier** is a web-based deep learning application that analyzes short voice recordings to detect **respiratory anomalies or possible infections**. The system records user speech, converts it into audio features, and uses a **CNN-based classification model** to predict health status.

---

##  How It Works

1. User clicks **Record (5s)** and speaks for 5 seconds.
2. The recorded voice is processed into audio features.
3. The CNN model analyzes the extracted features.
4. The system predicts whether the user is:
   -  **Healthy**
   - ⚠ **Infected**
5. The output is displayed along with prediction probabilities.

Best results are achieved with:
- Clear voice
- Low background noise
- Microphone access enabled

##  Model Details

- Model Type: **Convolutional Neural Network (CNN)**
- Task: **Binary Classification (Healthy vs Infected)**
- Input: **Speech Audio**
- Feature Extraction: **Audio Spectrogram / MFCC**
- Output: **Probability-based Health Prediction**
