Problem Statement

Early detection of respiratory infections is essential for preventing serious health complications. Traditional diagnosis requires clinical tests and hospital visits. This project demonstrates an AI-based system that detects respiratory anomalies using recorded human speech.

Working Process

  • User records a 5-second voice sample
  • Audio features are extracted using MFCC
  • CNN model analyzes the features
  • System classifies as Healthy or Infected
  • Probability scores are displayed

Technologies Used

Python | TensorFlow | CNN | Librosa | FastAPI | HTML | CSS | JavaScript | GitHub

Results

The system successfully detects respiratory infections from voice input with good accuracy. It displays probability confidence levels and works best with clean microphone input and low background noise.
